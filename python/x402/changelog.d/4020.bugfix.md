The exact EVM facilitator (V1 and V2) now returns `invalid_exact_evm_payload` from `verify` and `settle` for malformed EIP-3009 and Permit2 payloads (missing or wrongly typed authorization fields, non-hex or wrong-length EIP-3009 nonces, numeric fields that are not uint256 decimal strings) instead of raising. Numeric fields sent as JSON numbers are now rejected, matching the Go facilitator. `invalid_message` / `error_message` names the malformed field.
